Wobbledink: система документацииWobbledink: a documentation system

В гейм-дизайн-документах одни и те же термины и числа повторяются на многих страницах и расходятся после первой правки баланса. Wobbledink хранит их в справочнике и подставляет в текст актуальные значения. Сейчас это веб-приложение команды и расширение для Google Docs, а для VS Code готов reader, на котором строю третью версию.Game design documents repeat the same terms and numbers across many pages, and they drift apart after the first balance pass. Wobbledink keeps them in a glossary and puts the current values into the text. Today it runs as the team’s web app and a Google Docs extension, and a VS Code reader is the base for the third version.

Веб-приложениеWeb app

База знаний команды 2IQ: документы, термины и значения в одном месте. Клиент на Blazor WebAssembly, сервер на ASP.NET Core с PostgreSQL и SignalR, есть настольные сборки. Делаем с января 2025 года, на нём живёт документация Shards of Sanity.

The knowledge base of team 2IQ: documents, terms and values in one place. The client runs on Blazor WebAssembly, the server on ASP.NET Core with PostgreSQL and SignalR, and there are desktop builds. We started in January 2025; the Shards of Sanity documentation lives there.

Wobbledink G-DocsWobbledink G-Docs

Расширение для Chrome. В тексте Google Docs пишу [термин] и {значение}, справочник лежит в Google Sheets на двух листах. В режиме просмотра документ показывает актуальные значения, при наведении открывается карточка термина, а в ней вложенные карточки. Сам текст документа не меняется. Чтобы выйти в магазин Chrome, расширению нужна проверка OAuth у Google.

A Chrome extension. In Google Docs I write [term] and {value}; the glossary is a Google Sheets spreadsheet with two sheets. In viewing mode the document shows current values, and hovering over a marker opens a term card with nested cards inside. The document text itself stays unchanged. To go public in the Chrome Web Store, the extension needs Google’s OAuth review.

Wobbledink LightWobbledink Light

Reader Markdown для VS Code: документ открывается в газетной вёрстке со шрифтом PT Serif, в нём работают поиск и переходы по ссылкам. Только чтение, файлы он не меняет. На его основе пишу полное расширение с терминами и значениями.

A Markdown reader for VS Code: a document opens in a newspaper-style layout set in PT Serif, with search and link navigation. It is read-only and never changes files. I am building the full extension with terms and values on top of it.

Одна модельOne model

В веб-приложении и в Google Docs одна модель: термин с определением, значение с ключом и ссылки между ними. Расширение для VS Code получит ту же модель. Инструмент приходит туда, где команда уже пишет, и не заставляет переезжать. Связь терминов и значений между документами – тема моей диссертации в ЛЭТИ.

The web app and Google Docs share one model: a term with a definition, a value with a key, and links between them. The VS Code extension will get the same model. The tool goes where the team already writes instead of making it move. Linking terms and values across documents is the topic of my PhD at LETI.
